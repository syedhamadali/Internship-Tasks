About

Hi, I'm Hamad.

I'm a final-year BS Computer Science student at Abdul Wali Khan University Mardan, currently based in Lahore, working as a frontend web developer. I care about building interfaces that actually get used — which is why most of my projects start from a real gap I noticed rather than a tutorial.

My core stack is HTML, CSS and JavaScript, with React.js and Tailwind CSS for larger builds. I also work across React Native, Firebase and Supabase when a project needs a mobile or backend layer, and lean heavily on AI-augmented tooling to move fast without cutting corners on structure or accessibility.
